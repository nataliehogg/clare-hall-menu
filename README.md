# Clare Hall menu calendar

Scrapes the [Clare Hall weekly menu](https://sway.cloud.microsoft/b7Zz74Q2g96EIhE9) once a day and publishes a calendar (current week only) with an event for each lunch (12:00–13:30) and dinner (18:00–19:00), titled “CH lunch”, “CH dinner” or “CH closed”. The full menu is in each event’s description.

Subscribe in Google Calendar via *Other calendars → From URL* using the GitHub Pages link to `menu.ics`.

Run locally: `python menu.py` (needs Chrome or Chromium installed).
